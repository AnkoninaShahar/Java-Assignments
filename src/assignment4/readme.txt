DESCRIPTION:
In this lab, we implement the concepts of Inheritance and Polymorphism to model bank accounts and maritime vessels.
Project 1 [Savings Accounts]: This project uses the SpecialSavings class to extend a base SavingsAccount. It demonstrates inheritance by sharing protected accessors and implements polymorphism by dynamically applying a 10% interest rate to balances that exceed $10,000.
Project 2 [Ship Fleet]: The program includes functionality to assign various CargoShip and CruiseShip objects to a generic Ship array, demonstrating polymorphism by invoking overridden methods across the fleet.

HOW TO RUN:

Open the project in Eclipse.

Right-click on SavingsDriver.java (for Exercise 1) or ShipDriver.java (for Exercise 2).

Select 'Run As' then 'Java Application'.

The programs will automatically run the predefined test cases and display the results for the account balances, interest earned, and ship properties in the console window.
