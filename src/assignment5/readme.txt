DESCRIPTION:
In this lab, we implement file I/O and object relationships to analyze quiz scores for a class of students.
Project 1 [Student Data Modeling]: This project uses the Student and Util classes to read student data from a text file and populate an array of objects. It employs a modular package structure—model, util, and driver—to maintain a clean separation of concerns and uses StringTokenizer to parse IDs and scores.
Project 2 [Statistical Grade Analysis]: The program utilizes the Statistics class to calculate and display the high score, low score, and average for each of the five quizzes. It handles formatted output using printf to ensure statistical data is presented clearly and aligned for easy review.

HOW TO RUN:
1. Open the project in Eclipse.
2. Ensure data.txt is present in the project folder.
3. Right-click on Driver.java inside the driver package.
4. Select 'Run As' then 'Java Application'.
5. The program will parse the input file, skip the header line, and display the student score records along with the calculated high, low, and average statistics in the console.
