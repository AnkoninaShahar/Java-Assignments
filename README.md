# Java Assignments
**AUTHOR . . . . . . .** Shahar Ankonina  
**DESCRIPTION. . .** A comprehensive collection of Java object-oriented programming labs for CIS 35A covering foundational syntax, object-oriented principles, inheritance, polymorphism, file I/O, custom exception handling, object serialization, and the adapter pattern.

---
## About
This repository contains a complete, progressive sequence of Java laboratory assignments completed for CIS 35A. The coursework spans from early foundational concepts—such as basic syntax, control structures, and methods—to advanced object-oriented design including class hierarchies, inheritance, runtime polymorphism, robust file I/O processing, centralized custom exception handling with error logging, binary object serialization for state persistence, and the Adapter design pattern.

---
## Features
- *Assignment 0 & 1 [Foundational Syntax & Control Structures]:* Introduction to the Java development environment, primitive data types, conditional branching, and looping constructs.
- *Assignment 2 [Methods & Basic Classes]:* Core object-oriented fundamentals focusing on class definitions, field encapsulation, accessors/mutators, and method writing.
- *Assignment 3 [Arrays & Object Composition]:* Implementation of multi-element arrays, object aggregation, and data structuring within custom class frameworks.
- *Assignment 4 [Inheritance & Polymorphism]:* Models specialized bank account tiers (with dynamic interest rate application for balances over $10,000) and diverse maritime vessel types (`CargoShip`, `CruiseShip`) extending a base `Ship` class.
- *Assignment 5 [File I/O & Student Data Modeling]:* Utilizes `BufferedReader`, `FileReader`, and `StringTokenizer` to parse raw student performance records and calculate high, low, and average class statistics.
- *Assignment 6 [Exceptions, Serialization & Adapter Pattern]:* Implements custom exception handling (`StudentGradingException`), binary object serialization (`student_grades.ser`), and the `StudentAPI` adapter pattern for decoupled data access.

## Usage
- Open the project workspace inside Eclipse.
- Ensure input text files (`data.txt`) are correctly placed in the root project directory where required.
- Right-click the designated driver class for the target assignment and select **Run As → Java Application**:
- Console logs will output execution tracking, file verification status, error recoveries, and formatted statistical reports.
