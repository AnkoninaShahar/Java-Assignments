DESCRIPTION:
Project 1 [Nucleic Acid Class]: This program defines a NucleicAcid class that serves as a blueprint for storing chemical information of structural units in DNA and RNA. It stores the chemical name, formula, molar mass (float), and density (float).
Project 2 [Nucleic Acid Demonstration]: This program uses the GenoNucleicAcid driver class to collect chemical data via a Scanner and instantiate five unique NucleicAcid objects: Cytosine, Adenine, Guanine, Thymine, and Uracil. 
It demonstrates the use of constructors, encapsulation, precise floating-point formatting, and keyboard buffer management.

HOW TO RUN: 
1. Open the project in Eclipse.
2. Right-click on GenoNucleicAcid.java. 
3. Select 'Run As' then 'Java Application'.
4. Follow the prompts in the Console window to enter the name, formula, molar mass, and density for the five required nucleic acids.
