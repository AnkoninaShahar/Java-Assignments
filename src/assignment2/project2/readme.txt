DESCRIPTION:
Project 1 [Human Genome Class]: This program defines a HumanGenome class that acts as a blueprint for storing genomic data, including the genome name, number of genes, number of chromosomes, and the number of cells in the body (stored in trillions).
Project 2 [Genome Demonstration]: This program uses the GenomeInput driver class to collect data via a Scanner and instantiate three unique HumanGenome objects named after Disney characters. It demonstrates the use of constructors, encapsulation, and formatted output.  

HOW TO RUN: 
1. Open the project in Eclipse. 
2. Right-click on GenomeInput.java. 
3. Select 'Run As' then 'Java Application'. 
4. Follow the prompts in the Console window to enter the name, genes, chromosomes, and cell count for three different genomes.
