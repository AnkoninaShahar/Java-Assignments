DESCRIPTION:
In this lab, we implement the concepts of Association and Containment to model DNA structures.
Project 1 [DNA Model]: This project uses the DNA class to simulate a double helix. It demonstrates Containment by using arrays of NucleicAcid objects as instance variables and implements Association by sharing references to specific base objects (Adenine, Thymine, Guanine, and Cytosine).
Project 2 [Genome and DNA Analysis]: The program includes functionality to calculate the total density of both strands in the helix and identify the specific indices of nucleic acids that have the highest molar mass.

HOW TO RUN:
1. Open the project in Eclipse.
2. Right-click on DNADriver.java.
3. Select 'Run As' then 'Java Application'.
4. The program will automatically iterate through several test DNA sequences and display the results for the helix properties, highest molar mass, and total density in the console window.
